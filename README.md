# GenTe / TeaserAI: Video-to-Teaser Generator

A team project that aims to simplify the creation of engaging video teasers through automated video processing.

## Project Structure

- `frontend/` - User interface built with React and TypeScript.
- `backend/` - Python-based backend and video-processing pipeline.

## Features

- Video-to-teaser generation workflow
- Frontend-to-backend API integration
- Automated video processing
